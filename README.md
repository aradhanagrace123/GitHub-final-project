# Simple Interest Calculator

A simple Bash script that calculates simple interest given the principal amount, annual rate of interest, and time period in years.

## Formula Used
text
Simple Interest = (Principal * Rate * Time) / 100

## Inputs
* *p*: Principal amount
* *t*: Time period in years
* *r*: Annual rate of interest

## Outputs
* *Simple Interest*: The calculated interest amount

## How to Run
bash simple-interest.sh
